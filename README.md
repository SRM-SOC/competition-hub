# 🚀 SRM-SOC — SRM Summer of Code

**SRM-SOC** is an open source contribution competition organised by students of **SRM Institute of Science and Technology**. Inspired by Google Summer of Code, SRM-SOC gives you a structured 4-week program to contribute to real projects, earn points, and compete on a live leaderboard.

## ⚡ How It Works

```
1. Register on Discord → link your GitHub account
2. Browse open issues across all projects
3. Claim an issue using /claim in Discord
4. Fork the repo, create a branch, make your changes
5. Raise a PR following the correct format
6. Get reviewed and merged → earn points automatically
7. Climb the leaderboard 🏆
```

## 🛠️ Getting Started

**Step 1 — Join Discord and register**
Join our Discord server and run `/register` in the `#register` channel to link your GitHub account.

**Step 2 — Do your onboarding PR**
Head to the [onboarding issue](https://github.com/YOUR_ORG/competition-hub/issues/1) and add yourself to `CONTRIBUTORS.md`. This is your first PR and earns you 5 free points.

**Step 3 — Pick an issue**
Browse issues in any project repo or check the `#issues-*` channels in Discord. Use `/claim` to reserve an issue.

**Step 4 — Contribute**
Read the [Contributing Guide](./CONTRIBUTING.md) for branch naming, PR format, and all the rules.
